# 📅 Calendário Interativo & Organizador de Eventos

Um aplicativo web de calendário moderno e dinâmico, desenvolvido com **JavaScript Vanilla**, **HTML5** e **CSS3**, projetado para oferecer uma experiência de usuário rica com temas customizáveis e gerenciamento de compromissos.

---

## 🎯 Sobre o Projeto

Este projeto foi construído para explorar a manipulação avançada de datas no JavaScript, além de treinar componentes de interface interativos usando elementos nativos do HTML5 (como a tag `<dialog>`) e estilização flexível com CSS.

---

## ✨ Funcionalidades Principais

* **🔄 Alternância de Visualização:** Alterne facilmente entre a opção de visualização **Mensal** e **Semanal**.
* **🌓 Modo Claro / Escuro (Dark/Light Mode):** Chave de estilo interativa integrada para alternar o tema do aplicativo.
* **🖼️ Temas Personalizados:** Galeria de fundos dinâmicos baseada em imagens da natureza e espaço (florestas, montanhas, astronauta) para personalizar a interface.
* **📝 Adição de Eventos:** Modal integrado para inclusão rápida de compromissos vinculados a datas específicas do calendário.
* **📱 Navegação Intuitiva:** Setas de controle dinâmicas para avançar ou retroceder entre os meses.

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estrutura semântica, formulários e elementos modais (`<dialog>`).
* **CSS3:** Estilização avançada, variáveis de design e layouts responsivos.
* **JavaScript (Vanilla):** Lógica do calendário, manipulação do DOM, controle de eventos e navegação temporal.
* **Font Awesome:** Ícones vetoriais para interface (modo escuro, menu, setas e botões).
